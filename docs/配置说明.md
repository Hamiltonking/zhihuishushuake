# 配置说明

> 逐项解释 `config.toml` 的每个键：默认值、作用范围、改了会怎样、哪些别碰。
> 配套阅读：[使用指南.md](使用指南.md)（安装 / 登录 / 刷课流程）。

---

## 1. 配置文件在哪

| 项 | 值 |
|----|-----|
| 真实路径 | `~/shua/zhs/config.toml` |
| 工具读取路径 | `./.zhs/config.toml`（`.zhs/config.toml` 是指向仓库根 `config.toml` 的软链） |
| 生成方式 | `zhs init`（已存在则不会覆盖） |
| 权限 | `chmod 600`，因为里面有 API Key |

改之前先备份，改坏了能退回去：

```bash
cp config.toml config.toml.bak
```

## 2. 改完什么时候生效

**每次运行命令时重新读取**，不需要重启任何服务；正在跑的后台任务不会热更新——要让新配置生效，得停掉再重开：

```bash
pkill -f "[r]esume_homework"                                   # 停
setsid nohup .venv/bin/python tools/resume_homework.py \
  课程ID 班级ID --max-tries 2 > personal/logs/hw.log 2>&1 < /dev/null &   # 重开
```

改完先校验一遍（TOML 语法错会直接抛异常，字段类型不对也会报）：

```bash
.venv/bin/python -c "
from zhs.config import ConfigManager
c = ConfigManager().load()
print('OK:', c.homework.ai_homework_threshold, c.ai.model, c.video.ai_threshold)
"
```

> ⚠️ 拼错的键**不会报错，也不会生效**（pydantic 忽略未知字段）。所以改完一定要回读确认。

## 3. 顶层字段

| 键 | 默认 | 范围 | 作用 |
|----|------|------|------|
| `save_cookies` | `true` | bool | 登录后把 Cookie 写入 `personal/cookies.json` |
| `limit` | `0` | 分钟，0=不限 | 整个 `play` 任务的时长上限，超时跳过当前课程 |
| `threshold` | `0.91` | 0.0~1.0 | **知到/Hike** 视频进度超过此比例即视为看完 |

> `threshold` 是小数（0.91 = 91%），和下面 AI 课程的 `video.ai_threshold`（0~100 整数）**不是一回事**，别混填。

## 4. `[video]`

| 键 | 默认 | 作用 |
|----|------|------|
| `zhidao_speed` | `1.5` | 知到视频倍速，最高 2.0 |
| `hike_speed` | `1.25` | Hike 视频倍速，最高 2.0 |
| `ai_speed` | `1.5` | AI 课程视频倍速，最高 2.0 |
| `ai_learn_optional` | `false` | AI 课程是否也学「选学」资源（`true` 更耗时间） |
| `ai_threshold` | `90` | **AI 课程**视频完成百分比（0~100），到 90% 就算完成 |

想让 AI 课程视频更快结束，把 `ai_threshold` 调到 80~90；调到 100 意味着必须跑到结尾。

## 5. `[homework]`

| 键 | 默认 | 作用 |
|----|------|------|
| `threshold` | `100` | **知到**作业得分率达标线（< 此值重做） |
| `max_submit` | `0` | **知到**作业最大重做次数，0=无限 |
| `delay_min` / `delay_max` | `1.0` / `2.0` | 每题保存后的随机延迟（秒），防请求过快 |
| `page_size` | `100` | 扫描作业列表的分页大小 |
| `ai_homework_threshold` | `90` | **AI 课程**掌握度闸门：`masteryScore > 此值` 就跳过该知识点作业 |
| `skip_ai_free_exam` | `true` | AI 作业是否跳过 `freeExam=1` 的知识点（这类不计入掌握度） |

### 5.1 `ai_homework_threshold` 到底怎么生效（最容易搞错）

代码里有两道判定，比较符号**不一样**：

| 位置 | 条件 | 结果 |
|------|------|------|
| `_run_homework_only` 开头 | `mastery >= 阈值` | 整个知识点直接跳过（连 PPT 都不读） |
| 作业循环内 `_should_do_homework` | `mastery > 阈值` | 停止重做，保留当前分数 |

举例，阈值 `80`：

| 当前掌握度 | 行为 |
|------------|------|
| 0 ~ 79 | 进作业循环，做作业（默认不限次数，直到 >80） |
| 80 | 开头判定 `80 >= 80` 成立 → **跳过** |
| 81 ~ 100 | 跳过 |

再叠加 `--max-tries N`（本机脚本，见使用指南第 7 节）：

| 当前掌握度 | `--max-tries 2` 下的行为 |
|------------|---------------------------|
| 0 ~ 79 | 最多做 2 次；第 1 次拿到 81+ 就提前停 |
| 80 ~ 100 | 跳过 |

> `max_submit` 只管知到作业，**对 AI 课程完全无效**。AI 作业的天然兜底只有「分数 < 30 且已重试 > 4 次」，所以默认逻辑下 30~80 分之间会一直重刷，挂机时要盯着或用 `--max-tries`。

## 8. `[proxies]`

```toml
[proxies]
http = "http://127.0.0.1:7890"
https = "http://127.0.0.1:7890"
```

留空 = 直连。命令行 `--proxy socks5://127.0.0.1:7890` 会覆盖这里。

> `socks5://` 需要额外的 socksio 依赖，本环境默认没装，直接填会报
> `ImportError: Using SOCKS proxy, but the 'socksio' package is not installed`。
> 要用就先 `.venv/bin/pip install "httpx[socks]"`；否则用 `http://` 代理。

## 10. `[ai]`

| 键 | 默认 | 作用 |
|----|------|------|
| `enabled` | `true` | 总开关，`false` 则完全不做 AI 答题 |
| `use_builtin_ai` | `true` | **仅 AI 智慧课程**：`true` 用智慧树内置 AI（无需 Key，但很弱） |
| `api_key` | `""` | OpenAI 兼容 Key |
| `base_url` | `https://api.openai.com/v1` | 接口地址 |
| `model` | `gpt-4o-mini` | 模型名 |
| `max_token` | `27900` | **只用于 prompt 截断**（`max_chars = max_token × 4`），不是输出上限 |
| `stream_timeout` | `120.0` | 整个流的总时长上限（秒） |
| `stream_idle_timeout` | `30.0` | 相邻 chunk 空闲上限（秒），决定首包最长等待 |
| `web_search` | `false` | 按题干联网搜索，并把本地资料 + 联网结果一起给模型（DeepSeek `/v1/tools/search`） |
| `web_search_count` | `5` | 搜索返回条数（1~50） |
| `web_search_min_score` | `1.5` | 结果 `rerank_score` 下限（0~3，≥1.5 为优质） |

约束：`stream_timeout >= stream_idle_timeout`，否则加载配置时直接抛
`ValueError: stream_timeout 不能小于 stream_idle_timeout`。

### 10.1 `use_builtin_ai` × `api_key` 组合矩阵

| `use_builtin_ai` | `api_key` | AI 智慧课程 | 知到作业 / 知到考试 |
|------------------|-----------|-------------|--------------------|
| `true` | 空 | 内置 AI | ❌ 不可用（必须配 Key） |
| `true` | 有 | 内置 AI（Key 不生效） | ✅ 用 Key |
| `false` | 有 | 自定义 API | ✅ 用 Key |
| `false` | 空 | ❌ 不做 AI 答题 | ❌ 不可用 |

**结论：只要涉及知到，`api_key` 必填；想摆脱内置 AI，必须同时设 `use_builtin_ai = false`。**

### 10.2 联网搜索（可选）

AI 课程里有些知识点只有文本资源、没有 PPT，`_collect_completed_ppts` 拿不到任何参考资料，模型只能凭记忆答。开启后，工具会按题干调用 DeepSeek 官方搜索接口补充资料。

```toml
[ai]
web_search = true
web_search_count = 5
web_search_min_score = 1.5
```

- **所有题型都会搜**，本地资料（PPT/文本）排前面、联网摘要排后面，合并后一起喂给模型。
- 走 `POST https://api.deepseek.com/v1/tools/search`，用同一个 `api_key`，**约 5 元 / 1000 次成功请求**，无结果不计费。
- 填空题的「原文还原」优先用本地资料；本地没有资料时不做 LLM 改写——联网摘要噪声大，实测会把「海洋污染」改成「土地退化」。

### 10.3 常见后端

```toml
# DeepSeek
base_url = "https://api.deepseek.com/v1"
model = "deepseek-chat"          # 或 deepseek-reasoner（更慢更贵，思考型）

# Moonshot
base_url = "https://api.moonshot.cn/v1"
model = "moonshot-v1-8k"

# 本地 Ollama
base_url = "http://127.0.0.1:11434/v1"
api_key = "ollama"               # 随便填，不能为空
model = "qwen2.5:14b"
```

思考型模型只发 `reasoning_content`、正文为空，工具已把空 delta 当作活跃信号，不会被 `stream_idle_timeout` 误杀。

## 11. `[question_bank]`（可选）

```toml
[question_bank]
enabled = false
token = ""
query_url = "https://tk.enncy.cn/query"
info_url = "https://tk.enncy.cn/info"
scopes = ["zhidao_exam", "ai_exam"]
```

| 键 | 作用 |
|----|------|
| `enabled` | 开启后做题前先查题库，把命中答案作为提示喂给模型 |
| `token` | 在 `tk.enncy.cn` 个人中心获取，收费 |
| `scopes` | 生效范围，可选 `zhidao_homework` / `zhidao_exam` / `ai_homework` / `ai_exam`（可多选） |

题库命中率高时能显著提升分数；不用就别开，免得拖慢每题耗时。

## 12. `[crypto]` 与 `[urls]`：别动

```toml
[crypto]   # 与智慧树接口约定的密钥
[urls]     # 各业务域名的 API 基址
```

这两节是逆向出来的固定值，改了会导致签名错误 / 请求 404。除非接口整体迁移，否则保持原样。

## 13. 常用配方

### 13.1 只想快点把视频刷完

```toml
threshold = 0.90        # 知到/Hike 到 90% 就算完成
[video]
ai_threshold = 85       # AI 课程到 85% 算完成
zhidao_speed = 2.0
ai_speed = 2.0
```

### 13.2 想尽量拉高掌握度

```toml
[homework]
ai_homework_threshold = 80   # 低于 80 的都重做
skip_ai_free_exam = true     # 免考知识点不浪费时间
```

配合 `--max-tries 2` 控制次数，避免无限重刷。

### 13.3 想省 token / 省钱

- 换便宜模型（DeepSeek 比 GPT-4o 便宜得多）
- 把 `ai_homework_threshold` 设低（例如 75），少重做
- 用 `--max-tries 1` 只做一遍
- `max_token` 调小（例如 8000）可以截断超长 PPT 参考内容

### 13.4 容易触发风控 / 请求过快

把延迟调大：

```toml
[homework]
delay_min = 3.0
delay_max = 6.0

[exam]
delay_min = 5.0
delay_max = 10.0
```

## 14. 排错速查

| 现象 | 原因 | 处理 |
|------|------|------|
| 改了配置没反应 | 键名拼错（静默忽略） | 回读 `ConfigManager().load()` 确认 |
| 启动报 `stream_timeout 不能小于 stream_idle_timeout` | 两个超时顺序反了 | 让总时长 ≥ 空闲时长 |
| `Failed to parse config` / TOML 报错 | 语法错误（少引号、重复键） | `python -c "import tomllib;tomllib.load(open('config.toml','rb'))"` |
| 作业完全不跑 | `ai.enabled=false` 或 Key 为空 | 检查第 10 节组合矩阵 |
| 视频一直不结束 | `ai_threshold = 100` 或 `threshold = 1.0` | 降到 0.85~0.95 |
| 掌握度卡住不涨 | 阈值过高 + 单题总错 | 调低 `ai_homework_threshold`，换更强的模型 |
